# hxyfront-62002 剧场灯光Cue表管理

源提示词编号：2

做一个给剧场灯光师使用的灯位与Cue表管理前端项目，可以维护演出名称、灯具编号、通道号、色片、焦点位置、亮度预设和Cue触发顺序。页面需要有舞台平面灯位图、Cue列表、当前场景预览、灯具筛选和演出版本备注，适合排练期间快速调整。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62002

## 排练批注台

在 Cue 表基础上扩展为排练批注台，用于记录散排时灯光师留在某条 Cue 上的临时批注：

- 每条批注记录**内容、提出人、处理状态**（待处理 / 处理中 / 已处理），复排前可用筛选条一键只看**待处理**。
- Cue 通过 ↑↓ 调序时，批注以稳定 `cueId` 跟随**原 Cue** 移动，不会串到相邻条目。
- Cue 被「移走」后，其批注进入**失联区**：保留原顺序、原内容和原 Cue 名称快照，可单条或整组**重新挂**到现存 Cue（追加到该 Cue 批注末尾，组内顺序不变）。
- 数据自动保存在浏览器 localStorage，重开页面继续处理。

### 三层分离

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 批注数据 | `src/data/` | 类型定义、示例数据、localStorage 读写 |
| 重挂规则 | `src/rules/` | Cue 调序/移走、批注增删改状态、失联与重挂的纯函数及派生视图 |
| 列表界面 | `src/components/`、`src/App.tsx` | 筛选、Cue 卡片、批注条目、失联区展示 |

规则层不依赖 React，可直接对纯函数编写断言验证。
